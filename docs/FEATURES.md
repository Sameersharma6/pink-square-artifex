# Pink Square Artifex Store Features

## Customer
- Home, collection, search, category filters
- Product detail pages
- Photo / 3D View switch
- Real interactive 3D viewer when a public GLB/GLTF model URL is configured
- Customer registration and login
- Logout
- Cart and quantity controls
- Wishlist

## Admin
- Protected ADMIN role using JWT
- Admin dashboard at `/admin`
- Add product
- Edit product
- Delete product
- Change price and sale price
- Change stock/category/visibility
- Direct image URL/path field with preview
- Optional 3D model URL field
- Featured product flag

## Brand
- Pink Square Artifex logo extracted from the supplied brand poster and stored at `frontend/public/assets/pink-square-logo.png`.
